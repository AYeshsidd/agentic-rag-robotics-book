# Chapter 2: Cognitive Planning: LLM-based translation from language to ROS 2 actions

## Introduction to Cognitive Planning with LLMs

Cognitive planning for robots involves reasoning about goals, available actions, and environmental states to generate a sequence of steps to achieve a desired outcome. Large Language Models (LLMs) are revolutionizing this field by enabling robots to understand high-level natural language instructions and translate them into executable robot actions, bridging the gap between human intent and robotic capabilities. This chapter explores how LLMs can facilitate this translation, mapping complex language commands to structured ROS 2 actions.

## The Role of LLMs in Robotic Planning

LLMs, with their vast knowledge base and ability to understand and generate human-like text, can act as a high-level "brain" for robots. They can:

-   **Interpret Ambiguity**: Handle nuances and implicit information in natural language commands.
-   **Decompose Tasks**: Break down complex instructions into a series of simpler sub-tasks.
-   **Map to Robot Primitives**: Translate abstract concepts into concrete, robot-executable commands.
-   **Reason about Context**: Use general world knowledge to inform planning decisions.

## Translating Natural Language to ROS 2 Actions

The core challenge is to convert a user's natural language command (e.g., "Go to the kitchen and grab a cup") into a structured sequence of ROS 2 actions that a robot can execute. This often involves an intermediate representation.

### Intermediate Representations

Instead of directly mapping language to low-level joint commands, LLMs can output an intermediate representation that is more structured and easier for robotics middleware to interpret. Examples include:

-   **Task Graphs**: A sequence of high-level symbolic actions with dependencies.
-   **Semantic Action Plans**: A list of abstract robot actions (e.g., `move_to(location)`, `grasp(object)`) with parameters.
-   **ROS 2 Action Goals**: Directly generating ROS 2 Action goals (e.g., for navigation, manipulation).

### LLM Prompt Engineering for Robotics

Designing effective prompts for LLMs is crucial to guide them in generating appropriate robot plans. Prompts typically include:

-   **Robot Capabilities**: A description of what the robot can do (its available ROS 2 actions and their parameters).
-   **Environment Context**: Information about the robot's surroundings and known objects.
-   **User Instruction**: The natural language command from the user.
-   **Desired Output Format**: Instructions for the LLM to output the plan in a structured, machine-readable format (e.g., JSON, YAML, or a specific ROS 2 action message format).

## ROS 2 Actions for Complex Tasks

ROS 2 Actions are particularly well-suited for long-running, goal-oriented tasks common in robotic planning. An action client sends a goal to an action server, which executes the task, provides periodic feedback, and ultimately returns a result. This mechanism allows for robust execution of the plans generated by LLMs.

## Summary

LLMs enable robots to perform sophisticated cognitive planning by translating complex natural language instructions into executable ROS 2 actions. This process often involves intermediate representations and careful prompt engineering to align the LLM's generative capabilities with the robot's physical constraints and action space. Integrating LLMs with ROS 2 Actions provides a powerful framework for building more intelligent and autonomous humanoid robots.
