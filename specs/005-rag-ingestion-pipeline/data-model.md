# Data Model: RAG Ingestion Pipeline

**Purpose**: To define the structure and relationships of the key data entities used in the ingestion pipeline, as derived from the feature specification.

---

### Entity: `ContentSource`

-   **Description**: Represents a single source URL that the pipeline needs to ingest. This is the primary input to the pipeline.
-   **Attributes**:
    -   `url` (string, required): The fully qualified URL of the Docusaurus page to be processed.

---

### Entity: `ContentChunk`

-   **Description**: Represents a processed segment of text from a `ContentSource`, ready to be converted into an embedding. This is an intermediate data structure within the pipeline.
-   **Attributes**:
    -   `source_url` (string, required): The URL of the original page from which the text was extracted. This links the chunk back to its `ContentSource`.
    -   `section_identifier` (string, nullable): An identifier for the section of the page the chunk belongs to (e.g., "Chapter 1: Introduction", derived from `h1`, `h2` tags). Can be null if no clear section is identified.
    -   `chunk_index` (integer, required): The sequential index of the chunk within its parent section (or page, if no section is identified). Starts at 0 for each new section.
    -   `text_content` (string, required): The actual text content of the chunk.

---

### Entity: `VectorRecord`

-   **Description**: Represents the final data object that is stored in the Qdrant vector database. It combines the generated embedding with its associated metadata.
-   **Attributes**:
    -   `id` (string/UUID, required): A unique identifier for the vector record in the database.
    -   `vector` (array of floats, required): The semantic embedding generated by the Cohere model for the `text_content` of a `ContentChunk`.
    -   `payload` (object, required): The metadata associated with the vector. The structure of this object **is** the `ContentChunk` entity.

---

## Data Flow Diagram

```
[ContentSource (URL)]
        |
        v
[Web Scraper] -> Extracts raw HTML
        |
        v
[HTML Parser] -> Cleans and extracts main text content
        |
        v
[Text Chunker] -> Creates multiple [ContentChunk] entities
        |
        v
[Embedding Generator] -> For each [Content-Chunk], creates a `vector`
        |
        v
[VectorRecord Assembler] -> Combines `vector` and `ContentChunk` (as payload) into a [VectorRecord]
        |
        v
[Qdrant Loader] -> Upserts the [VectorRecord] into the vector database
```

---

## Validation Rules (from Specification)

-   All required fields for each entity must be present before being passed to the next stage of the pipeline.
-   The `source_url` in `ContentChunk` and `VectorRecord`'s payload must be a valid, non-empty string.
-   The `chunk_index` must be a non-negative integer.
-   The `vector` in `VectorRecord` must be a non-empty array of floats, with a dimension matching the Cohere embedding model's output.
