# Quickstart Guide: Module 3: The AI-Robot Brain (NVIDIA Isaac™)

## Getting Started

This guide provides a quick overview for setting up your environment and understanding the module's content structure.

### 1. Prerequisites

Before you begin, ensure you have the following installed:

-   **Operating System**: Linux (Ubuntu 20.04 LTS or 22.04 LTS recommended) with an NVIDIA GPU.
-   **NVIDIA Drivers**: Latest compatible NVIDIA GPU drivers.
-   **NVIDIA Isaac Sim**: Latest stable version installed. Follow official documentation for installation: [https://developer.nvidia.com/isaac-sim](https://developer.nvidia.com/isaac-sim)
-   **Isaac ROS**: Compatible version with Isaac Sim and ROS 2. Follow official documentation: [https://developer.nvidia.com/isaac-ros](https://developer.nvidia.com/isaac-ros)
-   **ROS 2**: Humble Hawksbill distribution or compatible with Isaac ROS. Follow official ROS 2 documentation for installation: [https://docs.ros.org/en/humble/Installation.html](https://docs.ros.org/en/humble/Installation.html)
-   **Docusaurus**: For viewing and contributing to the textbook content. Installation instructions can be found [https://docusaurus.io/docs/installation](https://docusaurus.io/docs/installation).
-   **Git**: Version control system.

### 2. Module Content Structure

The content for this module is located in the `docs/ai-robot-brain-isaac/` directory of the project repository. It is organized into chapters, as detailed in the `specs/003-ai-robot-brain-isaac/data-model.md`.

```text
docs/
└── ai-robot-brain-isaac/
    ├── chapter1.md
    ├── chapter2.md
    └── chapter3.md
```

### 3. Running Examples

Examples and conceptual demonstrations provided within the chapters will require NVIDIA Isaac Sim, Isaac ROS, and a functional ROS 2 environment. Specific instructions for running each example will be provided directly within the relevant chapter content.
