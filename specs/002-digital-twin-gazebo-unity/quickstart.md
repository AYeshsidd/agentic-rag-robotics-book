# Quickstart Guide: Module 2: The Digital Twin (Gazebo & Unity)

## Getting Started

This guide provides a quick overview for setting up your environment and understanding the module's content structure.

### 1. Prerequisites

Before you begin, ensure you have the following installed:

-   **Operating System**: Linux (Ubuntu 22.04 LTS recommended) for Gazebo, or Windows/macOS for Unity.
-   **Gazebo**: Gazebo Garden. Follow official documentation for installation: [https://gazebosim.org/docs/garden](https://gazebosim.org/docs/garden)
-   **Unity**: Unity LTS Release (e.g., Unity 2022 LTS). Download from: [https://unity.com/download](https://unity.com/download)
-   **ROS 2**: If integrating with ROS 2, ensure ROS 2 Humble Hawksbill is installed (refer to Module 1's quickstart or official ROS 2 docs).
-   **Docusaurus**: For viewing and contributing to the textbook content. Installation instructions can be found [https://docusaurus.io/docs/installation](https://docusaurus.io/docs/installation).
-   **Git**: Version control system.

### 2. Module Content Structure

The content for this module is located in the `docs/digital-twin-gazebo-unity/` directory of the project repository. It is organized into chapters, as detailed in the `specs/002-digital-twin-gazebo-unity/data-model.md`.

```text
docs/
└── digital-twin-gazebo-unity/
    ├── chapter1.md
    ├── chapter2.md
    └── chapter3.md
```

### 3. Running Examples

Simulation examples provided within the chapters will require either Gazebo or Unity. Specific instructions for setting up and running each simulation will be provided directly within the relevant chapter content.

### 4. Contributing

Refer to the project's main `README.md` and constitution for general contribution guidelines and standards.
