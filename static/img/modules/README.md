## Image Requirements

- Format: JPG, PNG, or WebP
- Size: Optimized to <200KB each
- Dimensions: Recommended 800x600px or similar aspect ratio
- Style: Professional, AI/robotics themed
- Alt text: Descriptive text for accessibility
